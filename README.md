# LAPL Digital Inclusion Explorer

An interactive Web GIS application developed for USC SSCI 591 Project 2.

This project visualizes digital inclusion resources available across Los Angeles Public Library branches. Users can explore library locations, click individual branches to view details, and filter branches by available digital resources.

## Features

- Interactive map of LAPL branch locations
- Branch information pop-ups
- Search/filter by digital inclusion resource
- Embedded ArcGIS Experience Builder application

## Technologies

- ArcGIS Online
- ArcGIS Experience Builder
- HTML / CSS
- GitHub Pages

## Data Source

City of Los Angeles Open Data — LAPL Digital Inclusion Resources.
