Los Angeles Public Library Digital Inclusion Explorer

This interactive Web GIS application maps digital inclusion resources available across Los Angeles Public Library branches. Users can explore branch locations, click individual library points to view branch information, and filter locations by digital resources such as iPad Minis, Hotspots, or Chromebooks. The application is designed to make branch-level digital access information easier to explore in a geographic context.

Explore the map

How to use the map

Explore library locations and the digital resources available at each branch.

  1. Pan and zoom to explore library branches across Los Angeles.
  2. Click a library point to view its branch name, digital inclusion resources, phone number, and hours.
  3. Use the resource filter to search for a service or technology such as iPad Minis, Hotspots, or Chromebooks.
  4. Clear the filter text to return to the full set of library branches.
